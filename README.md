## 📐 Overview

An interactive digital architecture showroom developed for Devil Labs (`devillabs.dev`) demonstrating:
- Real-time interior & exterior architectural walkthroughs in WebGL.
- Dynamic directional lighting, contact shadows, and ambient occlusion.
- High-resolution material inspection (concrete, brushed steel, tempered glass, hardwood).

---

## 🛠️ Setup

```bash
git clone https://github.com/vickyiitp/Devil-Labs-Architectural-Showcase.git
cd Devil-Labs-Architectural-Showcase
npm install
npm run dev
```
